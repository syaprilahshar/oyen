Privacy Policy — Oyen Run

Last updated: October 13, 2026

Summary

The game Oyen Run does not collect, store, or transmit any personal data. The game runs entirely on your device.

Data accessed by the app

Oyen Run only stores two items in your device's local storage (SharedPreferences). Both are removed automatically if you uninstall the app:

  • Best score — the highest score you have achieved
  • Language preference — whether the interface is displayed in Indonesian or English

Neither item can be used to identify you.

Data that is NOT collected

Oyen Run does not collect:

  • Any personal data (name, email, contacts, location)
  • Device data (IMEI, phone number, Google account)
  • Usage or analytics data
  • Advertising or ad-network data
  • Location data
  • Gameplay history sent to a server (there is no server)

App permissions

Oyen Run requests no sensitive permissions. The app runs in full-screen mode and plays sound effects through the standard audio channel.

Advertising and third parties

Oyen Run contains no advertising and uses no third-party SDKs for analytics, advertising, or tracking.

Children's privacy

Because this app collects no data from any user, including children, no child data is collected, stored, or transmitted to any server.

Policy changes

If this policy changes in the future, the updated version will be published on this page with a new revision date.
